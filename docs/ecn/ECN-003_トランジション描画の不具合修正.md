# ECN-003: トランジション描画の不具合修正

- **ステータス**: 適用済
- **種別**: 不具合修正
- **対象コミット**: `09ef10e`, `370f003`, `e70e62c`, `b45d08e`
- **影響ファイル**:
  - `stablestate.html`（`buildRoute()`, `renderSVG()` 内の遷移描画ロジック）

## コンテキスト

ECN-002で実装した直交遷移ルーティングにおいて、複数の遷移線が重なる・双方向遷移が区別できない・ブリッジ表示が片方向のみ動作するなど、実際の状態遷移図で使用した際に複数の描画不具合が発覚した。

## 問題の詳細

1. **遷移線の重なり**: 同一方向に複数の遷移がある場合、中間セグメントが同一座標を通り視覚的に区別不能
2. **双方向遷移の重なり**: A→BとB→Aが同一直線上にルーティングされ、2本の遷移が1本に見える
3. **到着/出発ポートの競合**: 同一辺で入出力の遷移がポートを共有し、線が重なる
4. **ブリッジ表示の不完全**: 水平交差のみブリッジが描画され、垂直交差では描画されない

## 対策

1. **チャネルオフセット導入**（`09ef10e`）: `buildRoute()`に`channelOffset`パラメータを追加。複数遷移が同一コリドーを通る場合、8pxずつずらして中間ルーティングチャネルを分離
2. **双方向遷移の代替ルーティング**（`370f003`）: A→B/B→Aペアを検出し、逆方向をbottom-bottomのU字型で迂回ルーティング。ラベル位置も方向認識型に変更（水平→上側、垂直→右側、13px間隔でスタック）
3. **エッジポートグループの統合**（`e70e62c`）: `srcPortGroups`と`tgtPortGroups`を`edgeGroups`に統合。同一辺の到着・出発を統一ポート空間で分配し競合を解消。チャネル間隔を8px→10pxに拡大
4. **ブリッジの双方向対応**（`b45d08e`）: 水平/垂直フィルタ（`isHoriz`）を撤廃し全交差にブリッジを描画。垂直セグメント用のarc sweep flagを追加。遷移種別（@external/@internal）のオレンジラベル表示も追加

## 結果

複雑な状態遷移図（10+状態、20+遷移）でも遷移線が視覚的に区別可能になった。双方向遷移、多重遷移、交差のいずれの場合でも正しく描画される。
