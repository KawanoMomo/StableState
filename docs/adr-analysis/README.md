## 対応優先度（統合）

### 不具合修正（即時対応）

1. **ADR-003** ラベル入力フォーカス喪失 — 実害が大きく修正も局所的
2. **ADR-001** VSCode ショートカット — VSCode拡張を使う場合に致命的
3. **ADR-006** 接続面選択 — 対角配置の状態で不自然な接続線が発生

### 改善反映（Phase 1.x）

4. **ADR-023** ポート間隔動的調整 — 1行変更で遷移線の見栄えが大幅改善
5. **ADR-018** 矢印キー移動 — 操作性の基本機能
6. **ADR-026-4** 検索/フィルタ — 大規模図でのナビゲーション必須

### 改善反映（Phase 2）

7. **ADR-015** RAF性能最適化 — 大規模図の操作性
8. **ADR-016** ID自動補正 — DSL可読性向上
9. **ADR-029** ストレステスト — 性能検証の基盤
10. **ADR-026-1** 遷移線幅カスタマイズ — 小変更で高効果
11. **ADR-027** bump-version.sh — バージョン管理自動化

### 将来検討（Phase 2-3）

12. **ADR-025** MCPサーバー — LLM連携の戦略的機能
13. **ADR-026-6** PlantUMLエクスポート — 他ツール連携
