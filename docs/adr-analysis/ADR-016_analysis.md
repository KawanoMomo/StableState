# ADR-016 分析: ID自動生成・補正機能

- **判定**: 部分実装 — 反映推奨
- **リスク**: LOW
- **対象ファイル**: `stablestate.html`

## StableBlockでの改善

`__new_N` プレースホルダID → ラベルからのID自動生成（labelToId）、30文字制限、Shift+クリックで全ID一括リネーム、重複ID検出。

## StableStateの現状

### 実装済

- **重複ID検出** (`stablestate.html:619-621`): パーサーで全要素のIDを照合し、重複時にエラー報告

### 未実装

| 機能 | 状態 |
|------|------|
| プレースホルダID (`__new_N`) | 未実装 — `state_1`, `grp_1` 等のカウンタ方式 |
| labelToId() | 未実装 — ラベルからのID導出機能なし |
| ID補正ボタン | 未実装 |
| 30文字制限 | 未実装 |
| Shift+クリック全IDリネーム | 未実装 |

## 推奨対策

1. 新規追加時のIDを `__new_N` プレースホルダに変更
2. `labelToId()` 関数を追加（小文字化、特殊文字除去、30文字制限）
3. ツールバーに「ID補正」ボタンを追加
4. Shift+クリックで全ID一括リネーム
