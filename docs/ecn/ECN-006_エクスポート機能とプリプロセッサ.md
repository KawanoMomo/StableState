# ECN-006: エクスポート機能とプリプロセッサ

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `b675c97`, `649e38d`
- **影響ファイル**:
  - `stablestate.html`
  - `tests/test-parser.html`

## コンテキスト

StableStateの状態遷移図を他ツール（PlantUML、Excel）と連携するためのエクスポート機能と、大規模DSLをモジュール分割するためのプリプロセッサが必要だった。またAUTOSAR開発で一般的な遷移線のスタイル区別（実線/破線、色分け）にも対応する必要があった。

## 対策

1. **遷移スタイル・PlantUMLエクスポート・Excelエクスポート**（`b675c97`）:
   - 遷移属性として`style=dashed`と`color=#HEX`をDSL構文に追加。SVGレンダラで破線・色付き遷移線を描画
   - PlantUMLエクスポート: StableState DSLからPlantUML記法に変換。状態、遷移、ノートを変換対象とし、PlantUML非対応の要素は`' NOTE:`コメントで出力
   - Excelエクスポート: 状態遷移表をExcel形式（.xlsx）で出力。ヘッダ行・列の自動生成、セル結合による見やすい表形式
2. **@includeプリプロセッサ・Auto-Route最適化**（`649e38d`）:
   - `@include`ディレクティブ: 外部`.sstate`ファイルをインライン展開。キャッシュ付きで同一ファイルの多重読み込みを防止
   - `autoRoute()`関数: 全遷移のポート割り当てを最適化し、交差数を最小化するワンクリック自動ルーティング
   - 124件のテストで検証

## 結果

PlantUML連携により既存のUMLツールチェーンとの互換性を確保。Excelエクスポートによりレビュー資料としての活用が可能に。@includeにより大規模状態遷移図のモジュール分割が実現し、チーム開発での分担が容易になった。
