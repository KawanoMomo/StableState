# ECN-043: 複合状態操作とドットパス対応

- **ステータス**: 適用済
- **種別**: 不具合修正・機能追加
- **対象コミット**: `4ae0b9d`, `9259fc2`, `54969bc`, `2289c13`, `bb0369a`, `f260897`, `0708573`
- **影響ファイル**: `stablestate.html`
- **関連ADR**: ADR-006

## コンテキスト

複合状態（composite state）の操作に複数の問題があった。

## 対策

1. **ドラッグ時の子の二重移動修正** (`4ae0b9d`): 子は相対座標なので親移動時にdragSetに含めない
2. **子要素追加UIとプロパティボタン** (`9259fc2`): 複合状態選択時に「+ 子状態/開始/終了」ボタンを表示。DSLの`{}`内に挿入
3. **非複合状態の自動複合化** (`54969bc`): 子要素追加時に`{ }`を自動付与
4. **空{\\}の自動除去** (`2289c13`): 最後の子削除時にremoveDSLElement内で空複合状態を検出し`{`を除去
5. **擬似状態のドットパス解決** (`bb0369a`): `resolveStateRef`で`parsed.pseudoStates`も検索
6. **遷移作成時のドットパス生成** (`f260897`): `stateDotPath(id)`新設。`connectTwo`/`connectSelected`/connectモード全箇所で使用
7. **fixIdsの擬似状態対応** (`0708573`): `__new_N`な擬似状態をtype名ベース（`ini`/`fin`/`choice`等）でリネーム

## 結果

複合状態の作成・編集・削除のライフサイクルが完結。子状態間の遷移が正しいドットパスでDSLに記録。
