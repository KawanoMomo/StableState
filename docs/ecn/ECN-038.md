# ECN-038: ラベルと擬似状態の重なり検出 + MCP API設計改善

## 不具合

validate_layoutがラベルと擬似状態の重なりを検出しない:
- uds_session→flashラベルがdiag_ini（始点●）に重なる
- startup→c_postラベルがc_post（choice◇）に重なる

## 対策

1. validate_layoutにチェック#10「ラベル vs 擬似状態」を追加
2. ss_auto_fixは削除。ループはLLM（呼び出し側）が担当
3. validate_layoutの出力をLLMが解析しやすい構造化フォーマットに変更
   - 各issueにtype, severity, element_ids, suggested_fixを含める
   - LLMがparse→判断→ss_modify→再validateのループを自律的に実行
