# ECN-002: コアエンジン実装（パーサ・バリデーション・レンダラ・同期）

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `c1bdb14`, `f590c8d`, `36ff56a`, `b94206b`, `8bad267`, `dca182f`
- **影響ファイル**:
  - `stablestate.html`
  - `tests/test-parser.html`
  - `tests/run-tests.js`
  - `CLAUDE.md`
  - `VERSION`

## コンテキスト

StableStateの中核となるDSL→SVGパイプラインをゼロから構築する必要があった。単一HTMLファイルにパーサ、バリデータ、SVGレンダラ、DSLアップデータを段階的に実装し、テスト駆動で品質を担保した。

## 対策

1. **プロジェクトスキャフォールド**（`c1bdb14`）: 3ペインHTML（エディタ・図・テーブル）＋ツールバー＋プロパティパネルの基本シェルを構築。591行
2. **DSLパーサ実装**（`f590c8d`）: 正規表現ベースの完全なパーサを実装。状態、遷移、擬似状態（initial/final/choice/history）、コンポジット状態、グループ、ノート、ディレクティブ（@canvas, @config）を網羅。テストハーネスも同時作成
3. **バリデーションルール**（`36ff56a`）: 参照チェック、初期状態必須、choice制約、config制約などの検証ルールを実装。エラー表示UIも追加
4. **SVGレンダラ**（`b94206b`）: グリッドパターン、グループ、コンポジット状態、リーフ状態、擬似状態のSVGレンダリングを実装
5. **直交遷移ルーティング**（`8bad267`）: ポート計算（ソース/ターゲットの相対位置ベース）、直交ポリラインルーティング、自己遷移ループ、交差検出とブリッジ/ホップ表示、イベント/ガード/アクションラベル表示を実装。364行追加
6. **DSLアップデータ**（`dca182f`）: 双方向同期のためのDSL更新関数群（`updatePos`, `updateSize`, `updateProp`, `updateLabel`, `addTransition`, `removeTransition`, `updateTransition`）を実装。13件のテストケースで検証

## 結果

DSLテキストからSVG状態遷移図への完全なパイプラインが動作。パーサ→バリデーション→レンダリング→双方向同期の全段階が単一HTMLファイル内で完結し、外部依存なしで動作する軽量アーキテクチャを実現した。
