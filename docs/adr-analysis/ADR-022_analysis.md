# ADR-022 分析: 接続線カラーピッカー

- **判定**: 未実装 — 反映推奨
- **リスク**: LOW
- **対象ファイル**: `stablestate.html`

## StableBlockでの改善

2ブロック選択時のプロパティパネルに12色カラーピッカーを追加。新規接続時に色指定、既存接続の色変更が可能。

## StableStateの現状

全遷移線が固定色 `#89DDFF`（シアン）でハードコード。

```javascript
// stablestate.html:1526
svg += `<path d="${d}" fill="none" stroke="#89DDFF" stroke-width="1.5" .../>`;
```

- 遷移パーサーに `color=` 属性の読み取りなし
- ステート/グループの色は設定可能（line 2024, 2066）だが、遷移には非対応
- ノート接続は固定黄色 `#FCD34D`（line 1594）

## 推奨対策

1. 遷移パーサーに `color=` 属性の解析を追加
2. 遷移レンダリングで `tr.color || '#89DDFF'` を使用
3. 2要素選択時のプロパティパネルにカラードットUIを追加
4. `@config` にデフォルト遷移色の設定を検討

UML状態遷移図では遷移の種類（正常系/異常系/タイムアウト等）を色で区別する運用が有効。
