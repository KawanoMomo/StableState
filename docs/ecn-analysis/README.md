## 対応優先度（統合）

### 不具合修正（即時対応）

1. **ECN-003** ラベル入力フォーカス喪失 — 実害が大きく修正も局所的
2. **ECN-001** VSCode ショートカット — VSCode拡張を使う場合に致命的
3. **ECN-006** 接続面選択 — 対角配置の状態で不自然な接続線が発生

### 改善反映（Phase 1.x）

4. **ECN-023** ポート間隔動的調整 — 1行変更で遷移線の見栄えが大幅改善
5. **ECN-018** 矢印キー移動 — 操作性の基本機能
6. **ECN-026-4** 検索/フィルタ — 大規模図でのナビゲーション必須

### 改善反映（Phase 2）

7. **ECN-015** RAF性能最適化 — 大規模図の操作性
8. **ECN-016** ID自動補正 — DSL可読性向上
9. **ECN-029** ストレステスト — 性能検証の基盤
10. **ECN-026-1** 遷移線幅カスタマイズ — 小変更で高効果
11. **ECN-027** bump-version.sh — バージョン管理自動化

### 将来検討（Phase 2-3）

12. **ECN-025** MCPサーバー — LLM連携の戦略的機能
13. **ECN-026-6** PlantUMLエクスポート — 他ツール連携
14. **ECN-026-8** Git Visual Diff — 協調開発支援
