# ECN-040: 状態遷移表のスクロール・配色・レイアウト改善

## 現状

フリーズペイン方式（ヘッダー/ボディ分離テーブル）を採用し、基本動作は安定。
以下の課題が未解決。

## 未解決課題

### 1. 横スクロール
- ボディは縦横スクロール可能だが、`table-layout:fixed` + `width:100%` のためセルが圧縮されて横スクロールが発生しない
- `table-layout:fixed`を外すと列幅同期が崩れる（headとbodyが別テーブルのため）
- 対策案: colgroup幅をJS計算後に両テーブルに適用し、`table-layout:fixed`は外す

### 2. 配色
- 現在のダークテーマ（var(--panel), var(--editor)）はコントラストが高く目がちかちかする
- 対策案: ネイビー/スレート系のミュート配色に変更

### 3. 状態名の配置
- 左上詰め統一

### 4. 列幅同期の信頼性
- requestAnimationFrameでbody→headのcolgroup同期を行っているが、コンテンツが変更されるたびに再計算が必要
- フォント読み込み前と後で幅が変わる可能性
- 対策案: ResizeObserverで自動再同期

## 試行済みで不採用

| アプローチ | 不採用理由 |
|-----------|-----------|
| border-collapse:collapse + position:sticky | W3C既知バグ。ボーダーがstickyに追従しない |
| border-separate + box-shadow疑似ボーダー | rowspanとstickyの組み合わせで状態が消える |
| rowspan廃止→flat cell grid | sticky top計算が複雑化、依然として状態消失 |
| rowspan z-index調整 | 根本的にstickyがrowspanに対応していない |
| 2行ヘッダー（パス表示） | 階層が読めない、ユーザー不採用 |
