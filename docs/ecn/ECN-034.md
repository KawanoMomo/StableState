# ECN-034: MCPサーバー generate_dsl() がコメントと書式を保持しない

## 不具合

MCP経由で`ss_save()`すると`generate_dsl()`がDSLを再生成するため:
1. DSL内のコメント（# 行）が全て失われる
2. 空行による視覚的な構造化が失われる
3. 座標が整数でも `3.0` のようにfloat形式で出力される
4. 擬似状態のparent情報がDSLに反映されない（ネスト内のinitialがルートレベルに出力される）

## 影響

MCPで編集→保存すると元のDSLの可読性が大幅に低下する。Git diffも大きくなる。

## 対策案

A: generatorを改善（コメント保持は困難 — parsedデータにコメントが含まれない）
B: MCP saveではgeneratorではなく、元のDSLテキストに対してregex置換で変更を適用する（StableBlockのupdatePos方式）
