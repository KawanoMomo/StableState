# ECN-044: 複数遷移ルーティングと個別管理

- **ステータス**: 適用済
- **種別**: 不具合修正・機能追加
- **対象コミット**: `f3773db`, `d08d27a`, `0673564`, `61b1ff1`, `6c9e55e`, `13167b9`, `5f48d29`, `b0b3e61`
- **影響ファイル**: `stablestate.html`
- **関連ADR**: ADR-003, ADR-007

## コンテキスト

同じブロック間に複数のイベント遷移を定義すると、矢印・ラベルが重なる問題があった。また遷移の個別操作（flip/delete/色変更）が同ペアの別遷移を巻き込んでいた。

## 対策

1. **複数遷移の接続許可** (`f3773db`): `connectTwo`にイベント名prompt追加。プロパティパネルに常時Connectボタン表示。`removeTransExact`新設
2. **逆方向ルーティング修正** (`d08d27a`): `reverseSet`を全逆方向遷移に拡張
3. **U字ルートのスプレッド** (`0673564`): `buildRoute`に`routeIndex`引数追加。U字legに30px/routeのスプレッド適用
4. **flipTransの正確な特定** (`61b1ff1`): from/to/event/guardの4値で特定（同ペアの別遷移を巻き込まない）
5. **findTransBetweenのドットパス対応** (`6c9e55e`): bare IDとドットパスの両方でマッチ
6. **矢印マーカーの個別色** (`13167b9`): 遷移ごとの色でSVGマーカーを動的生成
7. **行番号ベースの遷移操作** (`5f48d29`): 全操作をDSL行番号で一意識別。`removeTransByLine`/`flipTransByLine`/`setTransPropByLine`/`updateTransFieldByLine`新設
8. **擬似状態のpromptスキップ** (`b0b3e61`): initial/final等からの接続時はイベント名promptを表示しない

### 失敗した試み（revert済）

- ラベルだけをオフセットする方式 → 線と文字の対応が崩壊
- `channelOffset`に`_dirCount`で追加オフセット → 矢印が裏返る
- `getBoundingClientRect`→`offsetWidth`のcolgroup同期変更 → テーブル全壊

## 結果

同方向・逆方向の複数遷移が視覚的に分離。個別の遷移ごとに色/幅/スタイル/反転/削除が可能。行番号ベースの識別により同名イベントの遷移も正確に操作可能。
