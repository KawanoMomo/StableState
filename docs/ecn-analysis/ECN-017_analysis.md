# ECN-017 分析: ハイライトモード

- **判定**: 別アプローチで実装済 — 追加実装を検討
- **リスク**: LOW
- **対象ファイル**: `stablestate.html`

## StableBlockでの改善

Hキーで接続のないブロックを15% opacityにディミングし、接続のある部分のみを強調表示。`getConnectedIds()` で接続参加ブロックを特定。

## StableStateの現状

注釈編集モード（Nキー、3段階トグル）が類似の透過表示機能を提供しているが、目的が異なる。

| 機能 | StableBlock | StableState |
|------|-------------|-------------|
| トリガー | Hキー（2段階トグル） | Nキー（3段階トグル） |
| ディミング対象 | 接続のない要素 | 注釈編集時の全ブロック/遷移 |
| 判定基準 | 接続の有無 | モード（注釈編集 or 通常） |
| opacity | 0.15 | 0.35 |
| 目的 | 依存関係の可視化 | 注釈編集の視認性確保 |

### 未実装

- 接続の有無に基づくハイライト（`getConnectedIds()` 相当）
- 独立したハイライトモード（Hキー）

## 推奨対策

注釈モードとは別に、遷移の接続関係に基づくハイライトモードの追加を検討。状態マシン図では「遷移のない孤立状態」を発見する用途に有用。ただし注釈モードとの共存設計が必要なため優先度は低い。
