# ECN-042: 操作パラメータ統一とショートカット追加

- **ステータス**: 適用済
- **種別**: 機能追加・改善
- **対象コミット**: `dc338c6`, `1773d3f`, `bd93268`
- **影響ファイル**: `stablestate.html`

## コンテキスト

StableBlockとの操作感を完全に一致させるため、パラメータ統一と不足機能の追加が必要だった。

## 対策

1. **パラメータ統一** (`dc338c6`): ペーストIDを`__new_N`方式に統一。`addCounter`をオブジェクト→単一整数化。ズーム範囲3.0
2. **ショートカット追加** (`1773d3f`): `cutSelection()`新設。`toggleHighlight()`+`getConnectedIds()`新設。Ctrl+Shift+Z (redo)対応。キーボードハンドラ全面書き換え。ツールバーにHLボタン追加
3. **バッチ操作・遷移管理UI** (`bd93268`): `batchNudge`/`batchNudgeSz`/`batchProp`/`batchDelete`/`nudge`/`nudgeSz`新設。遷移管理関数群（`findTransBetween`/`connectTwo`/`removeTrans`/`flipTrans`/`setTransProp`）新設。プロパティパネルに複数選択バッチ操作UI・2要素選択時の遷移管理UI追加

## 結果

StableBlockと同等のキーボードショートカット体系、バッチ操作、接続管理UIが実現。
