## StableBlockでの改善

101ブロック、10グループ、139接続の大規模サンプル（`examples/stress-test.sb`）を作成し、性能ベンチマークとリグレッション検出に活用。

## StableStateの現状

### 既存のテストデータ

- `stablestate.html:182-205`: デフォルト例（5ステート、1 choice、8遷移）— 小規模
- `tests/run-tests.js`: ユニットテスト用の小さなDSLスニペット
- `tests/test-parser.html`: ブラウザテストハーネス
- `.sstate` ファイルなし、`examples/` ディレクトリなし

### 大規模テストの欠如

現在のテストデータでは性能問題の検出が困難。ECN-011（スナップガイド性能）やECN-015（ドラッグ性能）の問題はステート数が多い場合にのみ顕在化する。

## 推奨対策

`examples/stress-test.sstate` を作成。以下の規模を想定:

| 指標 | 目標数 |
|------|--------|
| リーフステート | 80+ |
| コンポジットステート | 10+ |
| グループ | 5+ |
| 遷移 | 120+ |
| 擬似ステート | 15+ |
| ネスト深度 | 3レベル |

状態マシンの構造例: 自動車ECUの制御モード遷移（Normal→Diagnostic→Failsafe→Recovery等）。
