# ECN-045: 状態遷移表の拡張

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `10cce45`, `11777d2`, `93fac44`, `cb8c822`, `cdd2a29`, `fb3c341`, `4a52132`, `8df0c71`, `80bc2aa`, `860c05a`, `00befc8`
- **影響ファイル**: `stablestate.html`
- **関連ADR**: ADR-004, ADR-005

## コンテキスト

状態遷移表にリーフ状態のみが列表示されており、複合状態への遷移が表現できなかった。またテーブルからの遷移編集UIが不十分だった。

## 対策

1. **複合状態のself列追加** (`10cce45`, `11777d2`, `93fac44`): `walkState`で複合状態を子のdepthにself列として追加。ancestryに自身を含めて`depth===chain.length`を維持。stateIdに`_self`suffix。ヘッダーラベルは空。子列の先頭に配置。（3回失敗→Node.jsシミュレーションで検証して成功）
2. **ROOT仮想列** (`cb8c822`, `cdd2a29`): テーブル先頭に`__ROOT__`列を追加。図には非表示
3. **プロパティパネル統一編集フォーム** (`fb3c341`, `4a52132`): テーブルセルクリックでtarget(プルダウン)/guard(input)/action(textarea)を一括表示。既存遷移は値をプリセット。新規遷移も同フォームで作成可能
4. **遷移先プルダウン** (`8df0c71`): 全状態をプルダウンで選択。空=@internal
5. **@internal遷移** (`860c05a`, `80bc2aa`, `00befc8`): target空で作成→`@internal`。図に描画しない。テーブルのtarget列は`-`。アクションなしの@internalは自動削除
6. **キャンバスサイズ編集** (`fcf3839`): 未選択時のプロパティパネルにW/H/Grid入力欄

## 結果

テーブルから遷移の作成・編集・削除が完結。複合状態への遷移も表現可能。@internal遷移でアクション専用の定義が可能。
