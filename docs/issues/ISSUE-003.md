# ISSUE-003: 接続面選択アルゴリズムが対角配置・サイズ差で誤動作する

- **ステータス**: Open
- **種別**: 不具合修正
- **優先度**: MEDIUM
- **発見日**: 2026-03-28
- **影響ファイル**:
  - `stablestate.html`

## コンテキスト

`computePortSide()` 関数が中心点間の角度で接続辺を決定するアルゴリズムを使用している。StableBlockで同一問題が発見・修正済みだが、StableStateでも修正前のアルゴリズムが使われている。

## 問題の詳細

現在の実装（`stablestate.html:1180-1192`）は `dx` と `dy` の大小比較で接続辺を決定する角度ベースのアルゴリズム。以下のケースで誤動作する:

- **対角配置**: `dx ≈ dy` の場合、微小な位置変更で接続辺が突然反転する
- **サイズ差**: 大きいステートと小さいステートの間で、辺が実際には隣接しているのに中心点角度により反対側の辺が選ばれる

影響箇所:
- 通常遷移のポート計算（line 1420）
- 逆方向遷移のポート計算（line 1411）
- ノート接続のポート計算（line 1584）

修正方法はエッジギャップアルゴリズムへの置き換え（各方向のギャップ量を比較して最大ギャップ方向を接続辺とする）で、StableBlockの修正済みコードを参照できる。
