# ECN-036: ピクセルレベルレイアウト検証の強化

## 不具合

1. 子状態が親状態からはみ出している（cruise at 6+3=9 > active h=8）
2. 擬似状態が遷移線と視覚的に重なっている
3. ラベルテキストが他の要素と重なっている
4. 既存validate_layoutがグリッド単位の粗い検出で見逃す

## 対策

validate_layoutをピクセルレベルに強化:
- 子状態/擬似状態の親内収まりチェック（マージン付き）
- 遷移ルートの全セグメントと全要素のピクセル交差判定
- ラベル矩形の推定と重なり検出
- 自動修正: 親の拡大、子の再配置、ラベルスペース確保
