# ECN-005: UIインタラクション機能

- **ステータス**: 適用済
- **種別**: 機能追加
- **対象コミット**: `7f54ebd`, `575ad39`, `0778120`, `e08cc8c`
- **影響ファイル**:
  - `stablestate.html`
  - `tests/test-parser.html`

## コンテキスト

コアエンジン（ECN-002）でDSL→SVGパイプラインが動作した後、ユーザーがGUI上で状態遷移図を操作・編集するためのインタラクション機能が必要だった。プロパティパネル、状態遷移表、アノテーション、エクスポート、接続モードなど、エディタとしての実用性を担う機能群。

## 対策

1. **プロパティパネル・遷移表・アノテーション・エクスポート**（`7f54ebd`）: 1,454行の大規模追加。
   - プロパティパネル: 状態選択時にラベル・色・位置・サイズを編集可能
   - 状態遷移表: 全遷移をマトリクス表示、セルクリックで遷移編集
   - アノテーション層: ノートの表示/非表示切り替え
   - エクスポート: SVG/PNG/クリップボードへのエクスポート機能
2. **アノテーション編集モード**（`575ad39`）: Nキーで3段階切り替え（OFF→ノート表示→編集モード）。編集モードでは状態/遷移が薄暗くなりノートが前面に表示される
3. **接続モード**（`0778120`）: ソース状態クリック→ターゲット状態クリックの2クリックで遷移を作成。従来のShift+click方式を置き換えるUX改善
4. **ID自動修正・グループ選択・labelToId**（`e08cc8c`）: `labelToId()`関数でラベルからID自動生成、`fixIds()`ボタンで重複/不正IDの一括修正、`groupSelected()`で複数状態をグループ化。122件のテストで検証

## 結果

テキストDSLとGUIの双方から状態遷移図を編集可能になった。特に接続モードとプロパティパネルにより、DSL構文を知らないユーザーでも直感的に図を操作できる。
