# ECN-039: Runブロックからの遷移ラベルがブロック外にはみ出す

## 不具合

以下の遷移ラベルがRunブロックの境界外に描画される:

1. `run → shutdown_seq`: ラベル「EvShutdownRequest / PrepareShutdown」がRunの左端外
2. `run → run`: self-loopラベル「EvWatchdogKick」がRunの右上外

## 原因

- レンダラーのラベル配置がルート中点ベースのため、長距離遷移ではラベルが接続元ブロック外に出る
- self-loopのラベルはブロック右上に固定描画されるが、位置調整機能がない
- validate_layoutの`label_out_of_canvas`チェックはキャンバス全体の範囲のみで、個別ブロックとの関係を見ていない

## 対策案

A: レンダラー側でラベルのクランプ（ブロック境界内に収める）
B: validate_layoutで「ラベルが接続元/先の共通祖先ブロック外にはみ出す」を検出
C: DSLでラベル位置のオフセット指定を可能にする（label_offset=x,y）

## ステータス

未対応。レイアウト調整（shutdown_seqを(15,36)に移動）で軽減済みだが根本解決ではない。
