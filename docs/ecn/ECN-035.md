# ECN-035: validate_layout検出不足 — 実ルーティングベースの検証が必要

## 不具合

MCP ss_validate_layoutは直線（center-to-center）ベースで交差を判定するが、
実際のレンダラーはorthogonalルーティング（L字/U字）でポイント列を生成する。
以下の問題を検出できていない:

1. コンポジットステート内の擬似状態が遷移線と重なる（実ルート基準）
2. 双方向遷移のラベル重複（レンダラーの迂回ルートで実際にどこに配置されるか）
3. ルーティングされた直交線がブロック上を通過するケース

## 対策

validate_layoutにcomputePortSide + buildRoute相当のPythonルーティングを実装し、
実際のポリライン経路に基づいて交差・重複を判定する。
