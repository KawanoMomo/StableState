# ECN-030: DSLエディタとダイアグラムのリサイズ + カーソル位置ズレ

## 不具合1: ペイン幅が固定

DSLエディタパネルが`width:320px`固定で変更不可。大きなDSLを編集する際に狭い。

**対策**: ドラッグ可能なスプリッターをエディタとダイアグラムの間に追加。

## 不具合2: カーソル位置とハイライトのズレ

`#editor`（transparent color + visible caret）と`#highlight-overlay`（visible color + pointer-events:none）の2層構造。`#highlight-overlay`は`overflow:hidden`のため`scrollTop`設定が効かず、テキストが長くなるとハイライトがスクロールに追従せず、カーソル位置とテキスト表示がズレる。

**対策**: `overflow:hidden`を削除し、スクロール同期で正しく追従させる。ただし`<pre>`自体がスクロール可能になると2重スクロールの問題が出るため、CSSでスクロールバーを非表示にする。
