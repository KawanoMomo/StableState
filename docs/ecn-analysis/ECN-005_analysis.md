# ECN-005 分析: ベジェ曲線の折れ

- **判定**: 対象外
- **リスク**: なし

## StableBlockでの問題

スタブ線+ベジェ曲線の接続部に角度の不連続が発生。

## StableStateの現状

StableStateは直交ルーティング（Manhattan routing）を採用しており、ベジェ曲線を使用していない。

- 遷移線は水平・垂直セグメントのみで構成（`buildRoute()`: line 1210-1315）
- 交差部にはアーク（ブリッジ）を表示（line 1492-1519）
- ベジェ曲線は一切使用していない

## 結論

アーキテクチャが異なるため問題パターンが該当しない。対処不要。
