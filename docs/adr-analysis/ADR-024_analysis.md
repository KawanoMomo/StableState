# ADR-024 分析: ベジェ曲線S字カーブ抑制

- **判定**: 対象外
- **リスク**: なし

## StableBlockでの改善

ベジェ曲線の制御点距離をブロック間ギャップの45%にクランプし、近接ブロック間のS字カーブを防止。

## StableStateの現状

直交ルーティング（Manhattan routing）を採用しており、ベジェ曲線を使用していない。遷移線は水平・垂直セグメントのみで構成（`buildRoute()`: line 1215-1350）。交差部のブリッジアークは6px固定の単純なSVGアーク。

## 結論

アーキテクチャが異なるため対象外。対処不要。
